One-line robot-vacuum excuse for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty ($5 prize pool, top 3). The program writes a single joke — the vacuum's cliff sensor mistakes a rug edge for a 400-foot drop, so it refuses to die for Dorito dust — to `entry.txt`. The joke is the winner of a 10-candidate head-to-head tournament judged with the competition's own judge brief: undefeated (9 wins, 0 losses).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
